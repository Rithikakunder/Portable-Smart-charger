# Wired Portable Smart Charger with Hybrid Power Source and Intelligent Load Management System

## Project Overview
This project is a portable smart charger that combines multiple power sources to charge multiple devices efficiently. It uses intelligent load management to distribute power while improving efficiency and supporting renewable energy.

## Features
- Hybrid power source (100W, 65W, standard adapter and solar)
- Multiple output ports
- Intelligent load management
- Simple and cost-effective design
- Supports solar energy integration

## Components Used
- ESP32
- Current and voltage sensors
- USB output ports
- Solar panel
- 100W and 65W power supplies
- Standard adapter

## Working Principle
The system combines multiple power sources to provide different output voltages for charging multiple devices. It manages power efficiently while reducing unnecessary power loss.

## Results
- Successfully charged multiple devices
- Improved power distribution
- Reduced dependence on a single power source


## Challenges Faced
- Maintaining a stable output voltage while using multiple power sources.
- Managing heat generated during operation.
- Ensuring proper power distribution for safe and efficient charging.
- Building a reliable hardware prototype.


## Future Scope
- Add IoT-based remote monitoring
- Include battery backup
- Implement fast charging protocols
- Design a PCB for a compact product
- Improve protection and safety features
